# JSON CV 与模拟学生访谈数据

本数据集按用户要求为系统测试编写，包含 **26 份 JSON CV、26 份访谈回答库、26 份规则回放记录和 26 份参考标签草稿**。每名学生有 2 段经历，共 52 段经历。全部身份、经历和测量数据均为虚构，没有真实学生访谈或真实成果证明。

从 [案例清单](CASE_INDEX.md) 选择案例。前 6 例为开发案例，后 20 例为评测候选。它们均由同一开发代理编写和检查，**不能称为独立 held-out**。

## CV 格式与参考来源

参考 `演示案例/Xiao Chuhe (Tracy) CV.docx` 的课程、经历、荣誉和技能栏目组织，以虚构校园场景重新编写；没有复制姓名、联系方式、原文或真实奖项。系统没有独立的荣誉与技能栏目，因此奖项进入对应经历的 `outputs`，技能进入该经历的 `skills`。

每份 `cv.json` 仅含系统可接受的 `student` 对象：`id`、`label`、`subjects` 和 `experiences`。课程包含 `name` 与 `predicted`；经历包含 `title`、`type`、`role`、`skills`、`outputs`。无需上传访谈标签或清单。未知成绩用空课程列表表示，不编造预估成绩。

测试时选择本地 `manchester_cs_ug`，上传 `cv.json` 即可开始。目标项目配置在清单中，未混入 CV。该项目要求仍需人工核实，本数据集不提供官方录取资格答案。

## 每例文件的用途

| 文件 | 用途 | 交给系统的方式 |
| --- | --- | --- |
| `cv.json` | 学生最初提供的简历 | 作为 CV 输入 |
| `interview.json` | 按经历和问题字段编写的模拟回答库 | 每次只发送当前问题对应的回答 |
| `simulated_transcript.json` | 当前规则访谈选择器实际问答的回放 | 用于检查流程；不是模型运行结果 |
| `gold.json` | 可成立/不成立论点示例、应发现缺口 | 仅给评分者，不发送给生成器或核查器 |
| `manifest.json` | 编号、来源、授权、分组和目标项目 | 评测管理，不作为学生事实 |

回答库包含每段经历的六要素，以及 `deep:concept`、`deep:alternative`、`deep:limit`，合计 468 条预设回答。按问题的 `experience_id` 与 `element` 取值；经历顺序必须保持不变。`[跳过]` 表示学生无法提供该回答，缺口仍应保留。

**不要将整份回答库提前交给系统。** CV 已填入的要素可能不会再被问到；完整回答库中的内容不等于系统已经收到或学生已经确认的事实。回放文件记录实际交付的回答和 `unasked_answer_fields`。实时模型可能改变问答路径，应按当次问题重新选择回答并记录实际过程。

## 覆盖范围与评分使用

案例覆盖充分证据、未测效果、贡献不清、CV 与访谈冲突、AI 辅助作品、阅读被拔高为研究、跨经历挪用事实、学生跳过问题、提示注入、局部性能测量、模拟与实体部署差异，以及英文回答。每例另配辅助经历，用于观察系统是否混淆经历、夸大专业关联。

`gold.json` 是待独立人工复核的参考草稿，论点示例不要求系统逐字输出。评分时必须依据**当次实际送入系统的事实**判断：事实能否支持具体措辞；已送达的关键缺口是否识别；有充分证据的内容是否被保留。未被询问的答案不能用于强制要求系统生成某条论点，也不能冒充核查依据。安全率须与覆盖率共同报告，避免删除所有论点就得到漂亮分数。

`expected_gaps` 指访谈后仍需确认的事实、范围或贡献，不是给学生安排后续学业规划。简历中的故意错误是冲突测试输入，不应直接当作已确认事实。

## 重现、版本与成本

在项目目录执行：

```sh
python3 -m eval.build_synthetic_profiles
```

此操作从固定案例规格重建文件，以真实 `normalize_cv` 校验输入，再使用当前访谈流程逐题回放并检查能够结束。26 例离线回放共 322 轮，每例 12–13 轮。**本次没有调用模型，API 调用数和 API 费用均为 0**；这不代表真实模型流程免费，也不提供模型质量分数。

`checksums.json` 保存本次 JSON 文件的 SHA-256；根清单保存生成脚本哈希。它们用于复现当前版本，不是独立评测的正式冻结。后续正式评测应先人工复核并确定版本，再冻结，之后不得根据结果修改同版数据。

已有 `eval.run_live` 使用旧的论点挑战集，尚未接入这份完整 CV 数据集。若运行新数据的真实评测，需让回放适配器读取新清单，逐题发送回答，记录每轮 tokens、生成和核查调用、重试、延迟与费用，并分别统计每例成本和全量成本。完整答案库不宜作为固定单次长提示替代访谈。
